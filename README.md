# sites.reverb256.dev

Generated sites for local businesses, built by the [site-agency](https://github.com/reverb256/site-agency) pipeline. Served at https://sites.reverb256.dev/.

- `/<slug>/` — public, claimable site for a business
- `/preview/<token>/` — token-gated private previews (noindex)

The pipeline commits here: `preview: <slug> [token]` for previews, `publish: <slug>` when a site goes public.
