# sites.reverb256.dev

Publish target for the [site-agency](https://github.com/reverb256/site-agency) pipeline — a consent-first system that surveys local businesses and upgrades their websites.

- `/<slug>/` — a business's published site (public only after that business consents)
- `/preview/<token>/` — private, token-gated preview (noindex) sent to the business for review

Coffee-shop demo sites were wiped 2026-09-22 (that sourcing parameter was a false premise); the pipeline itself continues.
